## Current focus

My current work focuses on **Enterprise Architecture, Cybersecurity and the adoption of AI in complex enterprise environments**.

A particular area of interest is **hybrid, local-first AI**: architectures that prioritize local or edge inference and processing while using policy-controlled escalation to cloud AI services when additional capability or compute is required.

This raises architectural questions well beyond model selection, including:

- Data sovereignty and privacy
- Identity and model access
- Security boundaries and isolation
- Observability and governance
- Resilience and connectivity
- Model routing and policy enforcement
- Enterprise platform integration
- Cost and operational sustainability

I explore these ideas through the open-source **Local Hybrid AI** project.

---

## Local Hybrid AI

[**Local Hybrid AI**](https://github.com/ea1het/local_hybrid_ai) is an open-source reference architecture for local-first hybrid AI focused on data sovereignty, security and policy-controlled cloud escalation.

It combines:

**Local inference • Model routing • RAG • Agentic workflows • Security • Observability • Governance**

The objective is not to avoid cloud AI, but to use local and cloud capabilities deliberately according to data sensitivity, model capability, latency, resilience and cost.
